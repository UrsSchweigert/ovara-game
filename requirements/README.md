# Requirements

One file per milestone of `PLAN.md` section 8. Each is the input to one harness plan:

    ./ov harness start --requirements requirements/M0-canon-and-foundations.md

Run them in order. Do not start a milestone until the gate of the one before has passed and you have signed it off.

- The investigator turns a file into phases and issues, and asks you questions when it is blocked. Read its report before you approve.
- A row's ID (`M0.1`) is what phases and issues refer to. Do not renumber rows once a plan has been approved.
- Later files are written from the plan as it stands today. Reread each one against `PLAN.md` before you run it, and edit it if the plan has moved.
- Workers cannot change this folder; it is on the harness's list of protected paths.
