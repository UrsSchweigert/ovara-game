# Canon

The world of Ovara as data. This folder is the single source of truth. Only the canon keeper edits it. It sits outside the Godot project in `game/` and is never shipped with the game; content refers to it by ID and the checks in `tools/` read it.

## Layout

```
glossary.yaml     canon terms and banned synonyms
index.md          GENERATED by `./ov index`: one line per entry. Do not edit.
source/           original prose: world bible, campaign, novel. Read-only.
proposals/        requested changes, one file each
places/           regions, holds, cities, landmarks
people/           named characters
factions/         corporations, peoples, groups
powers/           the gift: forms, reach, water states, costs
machines/         the craft: Maker devices, vehicles, the Thread
creatures/        animals and the fouled
flora/            plants and growths
events/           history and campaign events
chapters/         ch01.yaml to ch18.yaml: the state of the world at each chapter
```

## Entry format

One file per thing, named by its ID. Keep each under 40 lines; an agent should grasp it in one read.

```yaml
id: place.low-anthem            # type.kebab-name, never changes once created
name: Low Anthem
type: place
kind: hold
region: place.anthem-waters     # references are always IDs
summary: >                      # one or two sentences; shown in index.md
  Small farming hold of four hundred on the north Shoulder, under a
  Halcyon dumping route.
facts:                          # atomic, checkable statements
  - Population about 400.
  - One Maker dome; half its lamps are dark at campaign start.
  - Mostly Tenders.
look: Green-gold light, kelp terraces on every side, a meeting hall at the centre.
sound: The low chord of the kelp forest.
danger: Dumping from above; the Slick to the south.
links:
  people: [person.sefa, person.ione, person.hesper, person.elder-oro]
  creatures: [creature.tide-hound, creature.silverback]
  flora: [flora.anthem-kelp, flora.bitterwrack]
first_appears: ch01
changes:                        # how it differs over the campaign
  ch02: A third of the dome is flooded; 21 dead.
sources:                        # where each fact came from
  - world-bible.md#11
  - campaign.md#chapter-1
```

Required for every entry: `id`, `name`, `type`, `summary`, `facts`, `sources`.
Type-specific required fields are defined in `tools/schemas/`.

## ID rules

- Format `type.kebab-name`. Types: `place`, `person`, `faction`, `power`, `machine`, `creature`, `flora`, `event`.
- An ID never changes and is never reused. To retire something, set `status: retired` and say why.
- Names can change; references use IDs so nothing breaks.

## Chapter state files

`chapters/chNN.yaml` records what is true when chapter N begins:

```yaml
chapter: 5
title: The Lamps Go Out
region: place.anthem-waters
hero_name: Wrack                # he is Ilan Voss from ch08 onward in dialogue
hero_knows_past: false
hero_abilities: [power.listen, power.move, power.shape, power.hold, power.raise, machine.the-thread]
alive: {person.jef: false, person.elder-oro: false}
corporations_fallen: []
dragon: stalled
known_to_mariners: [jef-is-dead]
known_to_agravars: []
companions_available: [person.okonta]
```

Anything set in a chapter must agree with that chapter's file. The validator checks dialogue speakers, battle units, and the people placed in areas, dungeons and quests against `alive` and `companions_available`.

## Order of authority

When sources disagree during ingestion:

1. A decision the owner has recorded in `docs/decisions/`
2. The world bible, section 15 ("Decisions made")
3. The world bible
4. The campaign
5. The novel (authoritative for names, voices and scene detail only)

The short story `story-the-man-the-tide-brought-in.md` is an abandoned draft and is **not** canon. Do not ingest it.

Log every disagreement you find in `canon/proposals/ingestion-conflicts.md` rather than choosing silently.

## Changing canon

1. Anyone writes `proposals/YYYY-MM-DD-short-title.md`: what to add or change, why, which entries and content it affects.
2. The canon keeper checks it against existing entries and the world rules in `CLAUDE.md`, then asks the owner to approve.
3. On approval the keeper edits the entries, regenerates the index, runs `./ov check`, and moves the proposal to `proposals/accepted/`.
4. Rejected proposals move to `proposals/rejected/` with one line of reason, so nobody proposes them again.

New facts must not contradict existing `facts`. If a contradiction is intended, the proposal must say which old fact is being replaced.
